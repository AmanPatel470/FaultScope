
# FaultScope – API Failure Prediction & Blast Radius Analyzer

**FaultScope** is a microservice reliability and observability platform designed to detect abnormal API behavior, analyze service dependencies, estimate incident blast radius, and simulate service failures.

## Project Status

🚧 Work in Progress

## Planned Features

- Microservices-based application architecture
- API performance and health monitoring
- AI-based anomaly detection
- Dependency-based blast radius analysis
- Chaos engineering and failure simulation
- Interactive React monitoring dashboard
- Docker-based deployment

## Technology Stack

- Frontend: React.js, Vite, Tailwind CSS
- Backend: Node.js, Express.js
- Database: PostgreSQL
- Machine Learning: Python, Scikit-learn, FastAPI
- Monitoring: OpenTelemetry, Prometheus, Grafana
- Graph Analysis: NetworkX
- DevOps: Docker, Docker Compose
